# AI YouTube Factory — Admin

Internal **Next.js (App Router)** administration console. Shares the `@ayf/ui`
design system and theming with the frontend. Runs on port **3001**.

Phase 01 provides the authenticated shell and auth layout placeholder only — the
full admin panel (organizations, users, system controls) is built in a later
phase.

```bash
pnpm --filter @ayf/admin dev
```
